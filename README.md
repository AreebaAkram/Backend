⚡ FastAPI Backend
RESTful Backend API with FastAPI, SQLModel & SQLite

A lightweight backend application built with FastAPI and SQLModel, providing RESTful CRUD APIs backed by a SQLite database.

The project demonstrates core backend development concepts including API design, data modeling, validation, database operations, dependency injection, error handling, and asynchronous application lifecycle management.

🚀 Features
🔄 RESTful CRUD API — Create, read, update, and delete resources.
🗄️ Database Integration — Persistent data storage using SQLite.
📋 Data Validation — Request and response validation using Pydantic/SQLModel.
⚠️ Error Handling — HTTP exceptions and appropriate status responses.
💉 Dependency Injection — FastAPI dependency system for reusable components.
⚡ Async Support — Asynchronous application lifecycle and endpoint support.
📑 Automatic API Documentation — Interactive Swagger/OpenAPI documentation provided by FastAPI.
